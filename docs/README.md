# Documentation / Tài liệu

Start with the [project overview](../README.md), then choose your language for the complete manual. The shorter topic guides use English first with Vietnamese directly below.

Bắt đầu từ [giới thiệu dự án](../README.md), rồi chọn ngôn ngữ cho quyển hướng dẫn đầy đủ. Các hướng dẫn theo chủ đề có tiếng Anh trước, tiếng Việt ngay bên dưới.

- **English volume:** [read online](USER_MANUAL_EN.md) or [download the PDF](QuietShare-User-Manual-EN.pdf).
- **Quyển tiếng Việt:** [đọc trực tuyến](USER_MANUAL_VI.md) hoặc [tải PDF](QuietShare-Huong-Dan-Su-Dung-VI.pdf).

Both volumes cover installation, daily use, sharing workflows and every projection error code.

Cả hai quyển đều hướng dẫn cài đặt, sử dụng hằng ngày, các cách chia sẻ và toàn bộ mã lỗi trình chiếu.
