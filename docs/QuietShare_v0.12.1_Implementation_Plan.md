# QuietShare v0.12.1 - Zoom mặc định 50%

Nội dung web, tab web mới, code, ảnh và PDF mặc định mở ở 50%. Văn bản và lời nhắc dùng 12 pt, tương ứng 50% cỡ chuẩn 24 pt; code dùng 50% cỡ chuẩn 14 pt. Một giá trị mặc định dùng chung cho model, viewer và browser để tránh lệch nhau.

Nút đặt lại zoom và Ctrl+0 khôi phục mức 50%; vẫn cho chỉnh zoom 25-400% với web/code/ảnh/PDF và cỡ chữ văn bản theo giới hạn hiện tại. Tab giữ mức tự chọn độc lập trong phiên. PDF Vừa trang / Vừa ngang là lệnh chủ động căn theo khung, giữ nguyên ý nghĩa.

Giao diện điều khiển tiếp tục theo DPI Windows. Không thay đổi nội dung file, hồ sơ cá nhân, canary capture, trạng thái bảo vệ, quyền camera/micro hoặc luồng dừng trình chiếu.
